# CodeGuess

CodeGuess helps students practice Java through short code-reading and debugging challenges. It is designed for students learning Java who want to strengthen their understanding of program behavior, spot mistakes, and choose appropriate fixes.

## MVP

- Java challenges
- Answer checking
- Explanations for correct answers
- User accounts
- Progress tracking
- Bookmarks for saved challenges
- Admin content management

## Challenge formats

- **Predict output:** read a code snippet and choose its output.
- **Find error:** identify an error in a code snippet.
- **Choose fix:** select the change that fixes a problem.

Blank challenge templates are in [docs/sample-challenges.md](docs/sample-challenges.md).
